# Sistema Integrado de Gestão de Games (SIGG) Launcher

SIGG is the main UI process of the IFSCstation platform.

Features:
    - User Profiles (WIP)
    - Game Launching
    - Gamepad Support
    - Builtin Store (WIP)
    - Trophies Support (WIP)

PS: WIP features will need external software to work.
